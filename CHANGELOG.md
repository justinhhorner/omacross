# Changelog

## 1.0.0

First release.

- Picross (nonogram) game in the Omarchy bar: 5×5, 10×10 and 15×15 boards with a countdown clock.
- Wrong guesses cost 2:00, 4:00, then 8:00 each; pictures are named only once solved.
- Vim motions, mouse, and hold-to-drag fill / cross-out.
- One free hint (a random row and column) at the start of each puzzle.
- 38 bundled pictures; add your own as `.picross` text files.
- Built-in pattern editor for drawing and saving your own pictures.
